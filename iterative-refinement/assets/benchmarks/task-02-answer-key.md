# 基准任务 02 答案与评分（task-02-flawed-script.md）

## 使用方法（勿让被测执行者看到本文件）

1. **隔离答案**：先把 task-02-flawed-script.md 复制到技能目录之外的临时目录，再从该临时目录交给执行者；不得以技能目录内路径形式交付。
2. 在新会话中下达指令："请审查这段脚本的质量并修复，按迭代求精方式执行。"
3. 对照下表统计命中。**命中判据**：须定位到具体代码行并给出正确修复方向（如 D3 须指出空列表除零风险；泛泛说"代码不够健壮"不计命中）。
4. 评分：召回率 = 命中数 / 5；精确率 = 有效批评数 / 批评总数。独立运行两次取平均。合格线：召回率 ≥ 4/5 且精确率 ≥ 0.8。
