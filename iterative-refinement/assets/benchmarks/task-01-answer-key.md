# 基准任务 01 答案与评分（task-01-broken-tutorial.md）

## 使用方法（勿让被测执行者看到本文件）

1. **隔离答案**：先把 task-01-broken-tutorial.md 复制到技能目录之外的临时目录，再从该临时目录把任务交给执行者；不得以技能目录内路径形式交付（被测执行者若加载本技能，可直接列目录读到答案，测量将失效）。
2. 在新会话中下达指令，示例："请检查这份教程的质量并修正问题，按迭代求精方式执行。"
3. 执行者完成后，对照下表统计命中。**命中判据**：批评或修复须定位到缺陷的具体位置并给出正确方向（如 D1 须指出第二个 `-i` 应为 `-I` 或等效表述；泛泛说"命令可能有误"不计命中）。
4. 评分：召回率 = 命中数 / 5；精确率 = 有效批评数 / 其提出的批评总数。独立运行两次取平均。合格线：召回率 ≥ 4/5 且精确率 ≥ 0.8。
